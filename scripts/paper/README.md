# Computation scripts of the paper

These are the scripts named in Section 10 ("Computations and reproducibility") of the paper
[`paper/pi2-log2-golden-irrationality.pdf`](../../paper/pi2-log2-golden-irrationality.pdf). None of them is needed to check
the Lean proof: the formal certificate is generated by `../gen_cert_u.py` and re-checked by the Lean kernel.

Requirements: Python 3 with python-flint 0.9.0 (exact arithmetic and Arb balls), numpy and sympy. Run every command from
the folder that contains the script (`scripts/paper/` or `scripts/paper/m1/`). Results are written or appended to the
`runs/` folder next to the script; the committed files in `runs/` are the outputs the paper quotes.

Comments inside the scripts refer to section numbers of the working proof notes (`PROOF_U.md`, `PROOF_M1.md`), which are
not part of this repository. The mapping to the paper is given below.

the same machine with an earlier script (not included); the rows h ≤ 128 of Table 6 are taken from it, and `u_profile.py`
reproduces them (checked at h = 16). `law_check.py` reads it together with `runs/prof_h*.json`.

## Theorem M1, two points (`scripts/paper/m1/`)

| script | paper | command | output |
|---|---|---|---|
| `dual_ref.py` | Theorem 8.2 and Theorem 1.2 (§8.3, Table 4): the dual certificates for n = 730, …, 760 (written independently by an AI referee) | `python dual_ref.py n place d0 x0 ratio Xe rsub tag`, e.g. `python dual_ref.py 730 z 0.002 2.0 1.004 1300 16 z730_F` | `runs/dual_ref_out.jsonl` |
| `dualcert_arb2.py` (imports `dualcert.py`) | §8.3, Table 4: the certificates for n = 800, 1000 (plus a second certificate at n = 760 and the validation at √5 − 2, n = 0) | `python dualcert_arb2.py tag n place fine0 ratio sub`, e.g. `python dualcert_arb2.py z800 800 z 0.002 1.004 16` | `runs/dualcert_arb2_out.jsonl` |
| `facts_M1.py` | §8: the explicit numbers (fields, units, values of T, L) and the margins m(n), from the certificate rows | `python facts_M1.py` (seconds) | `runs/facts_M1_out.txt` |

Every row of `runs/dual_ref_out.jsonl` and `runs/dualcert_arb2_out.jsonl` records the parameters it was run with (`tag`,
`n`, `place`, and `d0, x0, ratio, Xe, rsub` or `fine0, ratio, sub`), so each certificate can be re-run from its row. The
density files (`runs/sigma_*.npz`) that the two certificate scripts also write are not committed.

`scripts/margin_v_cases.py` at the top level of the repository.

## Rigour

The certificates (`cert_U.py`, `dual_ref.py`, `dualcert_arb2.py`) and `facts_M1.py` feed the proofs: floating point is
used only to choose the density and λ, and every bound is evaluated in Arb, so any choice gives a valid bound.
`h0_U.py` uses exact finite sums with the constants of Theorem 5.1. The remaining scripts are checks of lemmas that are
proved in the paper; they are not used by the proofs.
